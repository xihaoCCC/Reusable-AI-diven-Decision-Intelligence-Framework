# Sample Data

This directory is for approved public-safe samples and data-access documentation.

The CTDC Global Synthetic Dataset v2026 and its codebook are currently excluded from
Git because redistribution permission has not been confirmed. Local copies may be used
for authorized research and model development, but users are responsible for obtaining
the data through an authorized source and following its terms.

Local or temporary source data should be stored in the sibling `Local_runner/`
workspace or another controlled local path, not committed here.

The current lightweight demonstration can generate CTDC-informed synthetic records at
runtime through `src.utils.generate_ctdc_style_synthetic_records`.

No real hotline, intake, referral, outreach, case-note, service, public-safety, victim,
or survivor records are included in this repository.
